> 范围：帮助中心易用性迭代（M1–M5）收尾时的职责边界与架构解耦扩展性审查。
> 结论：**无未决违规，允许正式启动 0.8.5。**

## 2. 职责边界结论

| 模块 | 职责 | 结论 |
| --- | --- | --- |
| `lib/helpContent.ts` | 内容注册表（文章 / 更新亮点 / 搜索源），纯数据 | PASS：不 import React 与组件层 |
| `lib/helpSearch.ts` / `lib/helpFeedback.ts` | 搜索与反馈纯函数 | PASS：无 UI 依赖，可独立测试 |
| `components/HelpCenter.tsx` | 帮助弹窗编排（分区、搜索、展开态） | PASS：不做内容加工，文案一律 i18n key |
| `components/HelpArticleCard.tsx` | 单篇文章渲染 | PASS：只消费注册表条目 |
| `components/PageHeader.tsx` | 通用页头布局 | PASS：保持通用，`actions` 可选插槽；不传时渲染结构不变 |
| `components/PageHelpButton.tsx` | 页面帮助入口 | PASS：仅传稳定 id，不含文案 |
| 页面 / 学业子组件 | 入口与空状态深链 | PASS：源码仅出现注册表内 id，无硬编码帮助文案 |
| Rust / 数据层 | 本轮未触碰 | PASS：零 schema、零命令、零依赖变更 |

## 3. 解耦与扩展性

- **新增一篇帮助文章**：`helpContent.ts` 注册一项 + i18n 双语 key，组件零改动；注册表校验测试与“遍历渲染全部文章”测试保证新增文章自动获得 UI 与搜索覆盖。
- **搜索**：`searchHelp` 纯函数消费 `HELP_SEARCH_SOURCES`，UI 层不实现匹配逻辑；未来接入 FTS5 或服务端搜索时替换数据源即可。
- **反馈**：`helpFeedback` 仅依赖 localStorage；0.8.10 动作日志 / 诊断包接入时替换该模块实现，UI 不感知。
- **稳定契约**：文章 id（`tasks.*` / `troubleshoot.*`）为深链与搜索共用标识，供 v1.2 知识库、v1.4 语言包复用；文案规范（`docs/COPYWRITING.md`）与质量门禁已入库。
- **Provider 位置**：`HelpCenterProvider` 移入 `Shell` 并新增可选 `onNavigate`，导航能力通过 prop 注入，帮助层不反向依赖页面路由实现。

## 4. 布局回归核对

- 四个主页面页头新增帮助按钮，其余页面、侧栏、列表行、工具栏、弹窗宽度未改动；`PageHeader` 默认渲染路径有结构测试锁定。
- 空状态仅追加次要按钮，原主操作全部保留（文件 / 项目 / 学业空态均有测试断言）。
- 帮助中心全部新 UI（五分区、搜索、文章卡片、反馈）限于弹窗内部。
- 学业页三处重复页头收敛为同一 header 变量，渲染结果一致。

## 5. 0.8.5 对接确认与遗留项

- **冲突面**：本轮改动仅前端 `src/` 与 `docs/`，与 0.8.5 的扫描器（Rust）、查询优化、keyset 分页无共享文件；前端查询/排序改动不触及帮助模块。
- **遗留项（不阻塞，进入 0.8.5 跟踪）**：
  1. 前端包体积 +13.1 KB（gzip），0.8.5 基准全量重测时记录并评估（帮助内容为静态 i18n，可按语言分包优化）。
  2. 0.8.5 新功能（快速扫描、查询优化）发布后需补充对应“更新亮点”与帮助文章条目。
  3. 帮助反馈数据暂无读取界面，0.8.10 观测版本接入时消费 `rootup.help.feedback.v1`。
- **结论**：自动化与人工核对均通过，无未决违规；0.8.5 可启动。
