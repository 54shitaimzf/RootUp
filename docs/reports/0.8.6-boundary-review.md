## 2. 0.8.6 扫描优化改动边界

- 改动面：`infra/mft.rs`（分 run 流式读取、原地 USA fixup、紧凑索引、子树定向、全量回退、大小兜底）、`infra/ntfs.rs`（USN 卷句柄访问级别与真实日志 ID）、`infra/scanner.rs`（skip_roots 传递与 MFT 门控）、`infra/index_store.rs`（多行 VALUES upsert）、`core/scan.rs`（仅默认 `batch_size` 常量 500→2000）。
- core 层无新依赖、无 Tauri 引用；`core/study_classify.rs` 中的 `infra::index_store` 引用仅存在于 `#[cfg(test)]` 测试内，生产代码分层未破坏。
- MFT 读取、解析、路径重建与枚举全部位于 infra，`FileEnumerator` 对外契约不变；失败/非 NTFS/无权限一律回退 walkdir，降级原因写日志。
- 大小兜底只作用于 `size_known=false` 的异常项（attribute-list extent 未解析到 `$DATA`），按路径补查元数据，失败时回退已解析大小；不改变正常路径行为。
- USN 修复属访问级别与参数正确性（`FILE_READ_DATA` + 真实 `UsnJournalID`），`DeltaSource` 契约与映射逻辑不变。
- 读取与批量微优化：MFT 卷句柄 `FILE_FLAG_SEQUENTIAL_SCAN` + 读块 32MiB；`upsert_many` 子批 1000 + FTS 表存在性单次检查；walkdir 枚举开始快照跳过集与时间戳。均为 infra 内部改动，对外契约不变。

## 3. 职责边界清单

- **增量数据源**：`core/delta.rs` 定义契约（DeltaKind / DeltaRecord / DeltaSource），`infra/usn_delta.rs` 实现 USN 启动补账；扫描器与 watcher 不感知实现细节，未来 0.8.8 配对迁移可直接替换映射。
- **MFT 枚举**：`infra/mft.rs` 实现 `FileEnumerator` 语义，门控（`ROOTUP_MFT_SCAN=1` + 管理员 + NTFS）+ 失败回退 walkdir；扫描器仅按结果选择，选择策略（阈值）预留为独立可配置项（`mft-verify.ps1` 输出阈值后落位）。
- **存储写入**：批量参数在 core 常量集中定义；`upsert_many` 多行 VALUES + 复用 prepared statement；WAL + `synchronous=NORMAL` 不变。
- **存储**：schema v5（usn_state）/ v6（FTS 版本占位）/ v7（移除 idx_files_type）；FTS 实现与同步保留但默认不建表，表缺失时写路径自动跳过——缓用隔离完整。
- **目录对账**：`core/path.rs::is_missing_dir_error` 纯判定 + scanner 对账 + `watched_dir_health` 命令 + 设置页标记；与 0.8.8 统一错误码体系预留衔接。
- **前端**：`lib/virtual.ts` 纯计算、`components/VirtualRows.tsx` 通用渲染（不依赖文件页业务）、FilePage 仅传入行渲染闭包；页面级 lazy 后 pages 仍是单向依赖，无循环引用。
