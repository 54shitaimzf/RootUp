## 2. 0.8.6 扫描改动边界

- **默认枚举器**：原生 Win32（`FindFirstFileW`）为默认 `FileEnumerator`；`ROOTUP_ENUM=walkdir` 诊断回退；MFT 仅 `ROOTUP_MFT_SCAN=1` + 优化器决策/强制开关时启用，失败一律回退并写 `scan: 快速扫描不可用` 日志。
- **诊断强制开关**：`ROOTUP_MFT_FORCE=1` 走 `core/scan_choice.rs::decide()`（force 优先、仍受 enable 门控），只用于验证脚本，默认发布路径不变；单测覆盖 force/disable/模型分支。
- **优化器**：双线性成本模型 + 迟滞在 core，扫描器仅消费决策；每次扫描回写校准（native / MFT 分项），无持久化（0.8.7 落持久化模型与阈值自动化）。
- **存储与查询**：schema v5（usn_state）/ v6 占位（FTS 默认不建表）/ v7（移除 idx_files_type）；`IndexStore` / `FileQuery` / `QueryPage` 对外契约不变；FTS 缓用隔离在 `SqliteIndexStore` 内部写路径。
- **基准基建**：`benchmark.ps1` 支持绝对 `ResultsDir` / `ExePath`；语料预生成复用（`ROOTUP_BENCH_PREPARE_ONLY/USE_CORPUS`、`ROOTUP_BENCH_PREPARE_FIXTURE/FIXTURE`）；渲染器修复 pre-release/dev 排序（`0.8.6-dev` 先于 `0.8.6`）。

## 3. 职责边界清单

- **core**：纯业务与契约（scan_choice / delta / query / path），无 Tauri 引用；测试中的 infra 引用仅限 `#[cfg(test)]`。
- **infra**：实现细节（mft / usn_delta / enumerator / index_store / scanner），不反向依赖 commands；降级与日志在 infra 内闭环。
- **commands**：参数校验与编排；新增 `watched_dir_health` 保持只读语义。
- **前端**：pages/features/components/lib 单向依赖；`VirtualRows` 通用组件不依赖文件页业务；帮助中心内容注册表与搜索/反馈为纯数据纯函数；页面仅提供入口与深链；默认文件页保留在首包（修复 lazy 化导致的首屏 IPC 延迟，主包 gzip 104.7 KB）。
- **数据流**：设置 → managed_state → 服务；事件 → 前端；基准与审计脚本不触碰用户正式数据（备份/还原 + 隔离夹具）。

## 4. 解耦与扩展性

- 新增扫描路径 = 实现 `FileEnumerator` / `DeltaSource` 契约 + 注册枚举器，core 零改动。
- 新增一篇文章 = 帮助注册表 + i18n 两项，UI/搜索自动覆盖。
- FTS 转正路径唯一（批量重建后启表 + 同事务同步），不引入触发器。
- 图标与单元同构（0.8.7）预留 `units` key 空间与图标注册表，不依赖 files 表结构。
- 性能指标命名进入统一注册表；0.8.6 单轨（0.8.5-rerun / 0.8.6-dev / 0.8.6）与后续版本可追加，旧系统基线已归档不移除（legacy/）。

## 5. 0.8.7 衔接清单

- MFT 默认启用：一致性 + 交叉点阈值双条件；持久化成本模型与阈值决策自动化（按上次索引文件数选择默认枚举 / MFT）。
- 启动体验：`notify` 递归监视器注册移入延迟服务或后台增量注册，消除大目录首次启动 4–8s 阻塞（0.8.6 四态实测发现）。
- 快速扫描提权链路：设置页「快速扫描（NTFS）」开关（默认关）→ 提权助手一次性授权 → 可选计划任务静默复用；主程序保持普通权限。
- FTS 批量重建后转正；标签查询收敛（FTS / 标签索引评估）。
- units 单元同构（file/project/software 统一 key 空间）+ 图标统一消费路径。
- keyset/COUNT 后续治理、DeltaSource 增量源配对、错误响应对账（0.8.8）。
