## 3. ≥15% 警示全集：原因与 0.8.6 去向

| 指标 | 变化 | 原因 | 0.8.6 去向 |
| --- | --- | --- | --- |
| 引擎扫描 100k | +41.5% | 三个索引的写入维护 + 本轮基准在重负载下运行，10k 持平而 100k 波动大（0.8.4 曾出现单次 3876ms 噪声） | 安静环境复核；评估索引延迟维护/部分索引 |
| 系统扫描 cold/warm | +17~18% | 同上（系统侧与 10k 引擎侧不一致，判为机器噪声主导） | 复核 |
| 索引库体积 | +24.4% | 新增 3 个索引的正常空间成本 | 评估覆盖索引与清理策略 |
| 重分类 100k | +50.4% | UPDATE 触发索引维护；样本课程名少时 AC 收益被写入成本掩盖 | 批量写入优化/索引裁剪复核 |
| 前端 JS gzip | +5.4% | 帮助中心内容与搜索（0.8.5 前置迭代） | 0.8.6 体积压缩与按语言分包 |
| 引擎扫描 10k / noise / wide | +0~16% | 各形状在噪声带内，mixed 持平 | 复核 |

查询侧全部为显著改善（-54% ~ -89%），无劣化警示。

## 5.1 发布卫生与 UI 审查结论

- **幽灵记录修复**：审查期间发现文件页总数比样例多 10——为两次冒烟测试在真实索引库留下的临时目录记录；冒烟脚本已增加收尾自清理（标记 deleted），并从真实库清理本次残留；该问题同时暴露“监控目录缺失后索引不对账”的产品缺口，已列入 v0.8.8 错误响应与对账机制。
- **设置文件 BOM 容错**：审查环境设置曾因带 BOM 写入导致应用解析回退为空对象；已确认应用侧对 BOM 的容错属健壮性缺口，列入 0.8.8 错误响应机制（损坏数据文件回退 + 提示）。
- **UI 审查结论**：帮助入口经多轮迭代定稿——页头“ⓘ 帮助”（Info 图标 + 文字，本页指南）、搜索框“?”（搜索语法）、侧栏“帮助与新手入门”浅色卡片（书本图标 + 短副标题 + 悬浮完整文案 + 版本徽标）；80 个样例文件完成加载更多、排序、搜索、AND 语法与深浅色核对，P1/P2 无未决。
