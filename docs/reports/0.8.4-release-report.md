## 2. 里程碑验证证据

### M0 基线冻结
- `bench-all.ps1 -Full` 7/7 通过，`smoke.ps1` 12/12 通过。
- 正式基线入库：`benchmarks/results/0.8.4.json`（系统）、`0.8.4.engine.json`（引擎），schema=2、含 host 指纹；`0.8.4-dev` 结果归档 `benchmarks/results/legacy/`。

### M1/M2 扫描器接口化与差集落库
- `FileEnumerator` / `ScanDiffStore` 契约位于 `core`；`WalkDirEnumerator` 保留忽略规则、跳过集与符号链接策略。
- 差集由 SQLite TEMP 表 + `mark_seen` 批量写入完成，内存占用 O(批次)；`finish(guard)` 用 LEFT JOIN 计算 missing，保留删除风暴保护与候选二次确认。
- 等价测试：同一语料下新路径与旧行为记录集合完全一致；10k 语料内存指标已记录。

### M3 jwalk 评估
- 评估报告：`benchmarks/jwalk-evaluation.md`；结论为 0.8.4 不引入依赖，0.8.5 再评估；`FileEnumerator` 插槽已就绪。

### M4 SQLite 调优与存储治理
- PRAGMA 组、墓碑清理（`purge_tombstones` / 启动幂等调用）、`checkpoint`/`optimize`、损坏备份保留 3 份、快捷图标对账、设置保存 500ms 合并防抖均有单测覆盖；churn/VACUUM 基线无退化（见第 4 节）。

## 5. 遗留风险与 0.8.5 对接点

- MFT/USN 快速扫描：0.8.5 实现为新的 `FileEnumerator` 实现，复用 `ScanDiffStore` 差集契约。
- keyset 分页 / COUNT 治理：0.8.5；本版本保留 OFFSET 分页与稳定排序。
- 显式多标签 AND 语法（如 `label:a +label:b`）：标签默认 OR 语义保持不变，语法增强随 0.8.5 查询优化落地。
- 性能警示（启动冷/暖 +62%/+67.6%、空闲内存 +16.9%/+44%、暖态内存 +26.3%）：0.8.5 性能迭代统一复测与优化；其余引擎扫描/查询类指标经复核回到 0.8.3 同量级。
- jwalk：0.8.5 依触发条件再评估。
- 中文排序：0.8.4 采用确定性字节序规则；拼音/ICU 排序不在规划内。
- 0.8.7 单元同构：以 `path_key` 为差集键，不依赖 files 表结构（本版本已统一大小写路径键）。
