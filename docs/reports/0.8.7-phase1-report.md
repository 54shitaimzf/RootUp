## 视觉核验（多模态前后对比）

- 方法：`scripts/seed-ui-review.ps1` 种入 90 个边界文件 → release 构建实测 → PrintWindow 窗口级截图（不受桌面遮挡影响）→ 拆解前（`baseline/`）后（`after/`）同路径矩阵对比。
- 矩阵：{深色, 浅色} × {zh, en} × {列表默认、名称排序激活、批量勾选、归档确认弹层、`label:` 自动补全下拉}，共 9 组（`docs/reports/assets/0.8.7-phase1/`）。
- 结论：布局、间距、图标与色点、弹层层级与遮罩、深浅主题、中英文案全部一致，无 P1/P2 回归。
- 预期内差异（非回归）：
  1. 列表顺序：种子文件 modified 时间戳随 seed 会话生成，同秒记录按 id DESC 的次序不同；
  2. 筛选 chips 排序：习惯快照（0.8.2 特性）随会话内点击频率变化；
  3. 归档弹窗预览文件名：复采时残留「名称↑」排序状态，勾选的前两行不同；
  4. 虚拟滚动阈值 >200 未触发（种子 90 条），与 0.8.6 基线一致由 VirtualRows 单测覆盖。
- 审查后已执行 `-Restore` 还原真实用户数据（settings/study/labels/schemes/db 五件套校验通过）。

## 给阶段二的交接

- `FileRow` props 为「记录 + 展示派生（presentRow）」：units 类型迁移只需替换记录类型与派生函数，行渲染与视觉不换。
- 事件注册表直接加新事件（fixture + 双端常量 + 测试），门禁自动覆盖。
- `theme/icons.ts` 是全库唯一图标断点，阶段三数据图标 key 注册表沿用「key → 视觉」形态（参照 `categoryDefs.ts`）。
- WatchService 回调已零 IO，阶段四定制监看引擎/USN 增量直接继承缓存推送模式。
