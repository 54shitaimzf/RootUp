# 文件监听与索引设计（FILE MONITORING）

> 本文档是"文件夹监听 → 文件索引 → 打开与快捷方式"迭代的设计依据。
> 实现范围与验收见 [ROADMAP.md](ROADMAP.md)。

## 设计目标与总原则

- 只响应"内容进入目录"，对用户在目录内的整理操作保持安静（不打扰、不抢文件）。
- 监视器可以敏锐，但必须克制：把文件系统噪声过滤成用户生活中的信号。
- 信任顺序：先证明软件"看得懂"文件（索引），再获得"移动权"（自动归档）。

## 整理方式演进（索引先行，物理归档渐进）

1. **索引**：文件落地后立即建索引（路径、大小、类型、时间、标签），不动文件。
2. **分类建议**：根据规则/偏好标签给出"该去哪"的建议。
3. **受控归档**：用户一键确认，或对重复模式记住选择后自动执行。
4. **全自动归档**：下载文件夹本身也井井有条（物理结构终局）。

物理组织是终局——用户在用资源管理器、微信传文件、IDE 打开项目时同样享受秩序；
但移动是失败模式最多的操作（跨卷、占用、引用失效、用户干预），
必须先以零风险能力建立信任，再逐步放开移动权。

## 文件状态机

```
出现 → 稳定确认 → 已索引 →（可选）已归档
```

- **出现**：create / rename 事件产生待处理条目。
- **稳定确认**：临时扩展名结束（rename）或大小稳定且可打开。
- **已索引**：写入索引库，可浏览 / 搜索 / 打开。
- **已归档**：物理移动到分类目录（受控或自动），并联动更新快捷方式。

## 场景策略与容错

| 场景 | 事件特征 | 应对策略 | 容错措施 |
| --- | --- | --- | --- |
| 下载单个文件 | 临时文件创建 → 持续写入 → 重命名 | 临时扩展名入忽略清单并标记"下载中"；重命名 = 完成信号；无重命名时用稳定确认兜底 | 下载取消/失败清理条目；残留临时文件超时静默忽略 |
| 编辑器批量保存 | 已跟踪文件的 modify 序列；`~$`、`#`、`~WRL` 临时文件 | 已跟踪文件 modify 不触发新条目；编辑器临时文件忽略；去抖合并 | 崩溃残留超时清理；临时文件重命名覆盖原文件视为保存，不重复弹窗 |
| 用户拖拽入库 | 成批 create / 目录树涌入 | 批量收敛为一条提示；文件夹按"单元"处理；默认只提示不移动 | 拖了又移走 → 瞬态清理；有界队列防卡顿 |
| 自动解压 | 我方发起 → 大量事件；外部解压同理 | 我方解压自行打标，完成后一次性汇总；外部解压走批量收敛 | 解压中断标记失败可重试；覆盖已知文件不重复弹窗 |
| 用户手动整理 | rename / delete / 新建目录 | 静默跟随：只更新索引，不提示、不撤销 | 归档前重查前置条件；目录删除后监听自动恢复或停止 |

## 通用容错层

- **状态机**：事件只驱动状态迁移，不直接执行不可逆操作。
- **去抖窗口**：2–3 秒合并批事件，防事件风暴。
- **稳定确认**：大小两次采样一致 + 可打开 = 稳定。
- **忽略清单**：临时扩展名/前缀统一管理，未来可配置。
- **幂等**：同一文件多事件不重复弹窗，按"路径 + 大小 + 修改时间"去重。
- **超时清理**：残留临时文件超时移除。
- **有界队列 + 慢消费保护**：监听线程不阻塞、不积压。

## 索引与分类

- 索引库字段：路径、大小、类型、标签、首次发现时间、最近修改时间、状态。
- 标签支持父/子层级与平行分类（数据库中维护，物理位置单份）。
- 单元机制：文件夹单元（项目/应用）与文件单元，单元内可设分类树。

## 打开与桌面快捷方式

- `OpenMethod` 模型：默认打开 / 指定程序（含参数与工作目录）。
- 能力：软件内一键打开（opener）；创建/更新 `.lnk` 到桌面。
- 联动：快捷方式归属索引条目；归档移动或用户挪动后更新目标或提示重建，保证路径始终正确。

## 模块落点

- `core`：`events`（状态机）、`index`（索引模型）、`open`（OpenMethod）。
- `infra`：`watcher`（notify + 事件归一）、`opener`（打开 + lnk）、`storage`（扩展）。
- `commands`：监控目录管理、文件查询、`open_item`、`create_shortcut`、`refresh_shortcut`。
- 前端：文件页（列表/搜索/打开/快捷方式）、设置页（监控目录管理）。

## 迭代拆分

- **迭代 A（进行中规划）**：事件管道 + 索引 + 文件页浏览 + 打开/桌面快捷方式 + 监控目录设置。
- **迭代 B**：分类建议（规则/偏好标签）与受控归档（含快捷方式路径联动）。
- **迭代 C**：全自动归档模式、单元分类树、撤销与路径跟随强化。
