# 开发路线图（ROADMAP）

> 本路线图由立项阶段的功能规划整理而来，按里程碑组织，后续可拆解为 GitHub Issues 跟踪。

## 当前状态

- v0.1.0（已完成）：Tauri v2 + React 框架与 UI 基础——系统托盘、关闭即销毁/托盘重建、单实例、主题三态、中英双语切换、设置持久化、左导航五页面骨架。
- v0.2.0（已完成）：文件监听与索引（迭代 A / A.5）——全量扫描与防误删、分类标签与搜索语法、可配置规则与方案、文件页门户、搜索自动补全与频率筛选、习惯数据收归应用管理、浮窗与皮肤基础、设置弹窗体验统一。
- v0.3.0（已完成，本迭代）：全面审查加固——修复实时合并截断与目录规范化同步；组件测试设施覆盖 UI 边界；`ui:` 行为日志与日志驱动冒烟；CI 完整构建、失败日志 artifact、冒烟与架构校验；架构依赖校验脚本。
- v0.4.0（已完成，本迭代）：项目识别与智能打开——项目页（自动发现 + 手动添加）、特征文件项目识别、成熟机制应用查找（PATH / App Paths 注册表 / 常见路径）、IDE 与常用工具智能打开、文件行三操作、桌面快捷方式智能唤起（单实例传参）、项目图标预置、AI 接口预留（`ProjectDetector`）。
- v0.5.0（已完成，本迭代）：UI 复用抽取与新手引导——共享组件 `Input`/`Select`/`InlineNotice`/`EmptyState`/`PageHeader`/`SyntaxTable` 替换手写样式；侧栏帮助中心（新手入门 / 搜索与高级用法）、首次启动欢迎弹窗（一次性可重看）、IDE 选择与官方下载指导、无 IDE 按需引导、已检测工具提示；后端 `list_detected_tools` 与 `open_url`（https 官方域名白名单）。
- v0.6.0（已发布，首个公开发布）：NSIS 安装包（per-user / 中英语言）、品牌图标全套、安装包自动验证脚本、GitHub Release 流水线、CHANGELOG。
- v0.7.0（已发布）：版本号规则与发布纪律落地——`npm run check:version` 五处一致性校验（CI 与 release 流水线强制）、安装包验证版本自动取自配置；标签管理设置弹窗（自定义标签注册表：显示名/图标/预设色板，内置大类只读）；受控归档与撤销（单文件/批量/筛选/项目单元 + 自动归档开关）；发布前手动验收见 docs/RELEASE_ACCEPTANCE.md。
- v0.8.0（已发布）：课程表与作业管理——课程表记录与学期设置（学期即课表，可新建/编辑/复制/删除）、作业管理（待办 / 已完成 / 已归档）、课程关键词纳入分类规则；学业数据后端持久化（study.json）并为 AI 预留上下文；发布前审查清理（标签筛选边界、线程竞态、采样间隔、批次号、项目回滚、批量重分类、locale 确定性排序）。
- v0.8.1（已准备发布）：学业提醒与设置稳固——作业截止提醒（默认关闭、可设提前量、学业页/列表/托盘直达）、关闭默认行为持久化（Settings v3）、语言下拉与 i18n 注册表、设置页分组、托盘菜单改进与“打开未完成作业”快捷路径。

## 版本规划（已固定）

> 以下版本主题为既定规划，实施顺序与范围以此为准；新功能不提前塞入，AI 能力单独成版。
> 配置蓝图（皮肤、扫描选项、AI 开关）按版本化约定在对应版本新增字段，不做空字段预留。

- **v0.8.1「学业提醒与设置稳固」**
  - ✅ 作业截止提醒：默认关闭、可设置提前量（学业页提示 + 作业列表临期/逾期分组 + 托盘 tooltip 计数与菜单直达；系统级通知后置评估）。
  - ✅ 语言切换改为下拉列表；i18n 后续准备：前端语言注册表 + 后端语言白名单 + 双字典三处同步约定，并清查硬编码文案。
  - ✅ 关闭默认行为持久化：`close_action: ask/background/quit`（默认 ask），Settings v2→v3 迁移，关闭确认弹窗支持“记住我的选择”。
  - ✅ 设置页分组与视觉统一（复用 FormSection / SegmentedControl 等现有组件）。
  - ✅ 托盘菜单改进：左键单击打开主窗口；菜单模型由纯函数生成（tooltip 显示临期作业数，子菜单直达临期/逾期作业并打开学业页对应项），`save_study_data` / `set_settings` 后动态重建，不轮询；自动归档开关与主题快速切换。
  - ✅ 桌面“一键打开未完成作业”快捷路径（`--open-homework` 启动参数 + `study-homework-open` 深链）。
  - 边界：不做 AI；不引入存储 schema 之外的架构改动。
- **v0.8.2「灵动视觉与反馈」**
  - 动效令牌：duration/easing 收敛到 `tokens.css`，统一现有 pop-in / deal-in 等散落动画。
  - 关键反馈动画：列表入场、归档/撤销成功、扫描进度、弹窗开合、提示条出现；只用 transform/opacity。
  - 提示增强：空态引导、操作结果反馈、快捷键提示；全局尊重 `prefers-reduced-motion`；深浅主题一致性复查。
  - 可选收尾：文件分类变更日志的最小实现（见 v0.8.3）。
- **v0.8.3「文件治理闭环」**
  - 智能解压：压缩包自动解压到独立文件夹，纳入索引/分类/归档链路；评估 zip 依赖与安全边界（路径穿越、解压炸弹、超大文件）。
  - 项目生命周期：一键规范命名 + 打包压缩 + 归档过期项目（复用 project / archive / shortcut 基础设施）。
  - 文件分类变更日志：记录分类/归档/撤销历史，可查看、可追溯、可一键撤销（复用 archive_ops / journal 模式）。
  - 快捷路径如未进 0.8.1 则放此。
- **v0.9.0「AI 能力」**
  - AI 分类与项目识别增强（`Classifier` / `ProjectDetector` 新实现）：API Key 设置、网络调用、错误处理、隐私说明；单独成版，不混入 0.8.x。

**迭代 B 执行顺序（稳固先行）**：反馈入口（Issue/PR 模板）✅ → 标签管理页 ✅ → 受控归档与撤销 ✅ → 课程表与作业管理（v0.8.0 已发布）→ 学业提醒与设置稳固（v0.8.1）→ 灵动视觉与反馈（v0.8.2）→ 文件治理闭环（v0.8.3）→ AI 能力（v0.9.0）。

范围与详细设计见 [docs/FILE_MONITORING.md](docs/FILE_MONITORING.md)：

- 监控目录设置：`Settings` 增加 `watched_dirs`，可增删、重启保留。
- 文件监听管道：notify + 事件归一 + 去抖 + 忽略清单 + 稳定确认 + 状态机。
- 文件索引库与文件页浏览（列表/搜索）。
- 独立日志系统模块（文件滚动日志，供所有子系统写入）。
- 验收：往监控目录丢文件，几秒内出现在文件页；下载中文件不误报；目录与配置重启保留。

里程碑 1 中的"文件夹监听"由本迭代覆盖；"快捷路径/智能分类/自动归档"在后续迭代实现。

## UI 与扩展基线

- 品牌基调：薄荷绿主色 + 中性灰，浅色/深色双主题（跟随系统），圆角 8–12px，柔和层级阴影。
- 设计令牌：`src/theme/tokens.css` 统一定义颜色、圆角、阴影与字体；皮肤 = 一套令牌覆盖，后续新增皮肤不改组件。
- 国际化：i18next + `zh-CN` / `en` 字典；新增语言只需添加字典并在后端校验常量登记。
- 后台策略：关闭即销毁窗口，后台零浏览器内存；托盘一键重建。

## 里程碑 1：MVP 核心能力

- 后台常驻：系统托盘显示图标，持续在后台运行。
- 文件夹监听：支持指定目录的实时变更监听（当前迭代）。
- 课程表记录：允许用户简单快速地创建课程表，并纳入分类体系（已落地：学期即课表 + 后端 study.json 保存 + 课程标签分类；AI 分类待后续迭代）。
- 自动解压缩：智能解压下载的压缩包，确保内容被解压到一个独立文件夹（v0.8.3）。
- 智能分类：下载完成后自动弹窗，根据文件名、类型与下载时间猜测分类标签，支持一键分类归档（v0.9.0，AI 能力）。
- 项目生命周期管理：清除/归档过期作业项目，一键规范命名并打包压缩（v0.8.3）。
- 快捷路径：创建自定义图标的打开脚本，可放置于桌面等醒目位置，一键打开未完成作业（v0.8.1 可选 / v0.8.3）。
- 临期提醒：作业到期前进行克制有度的弹窗提醒（v0.8.1，默认关闭、可设置提前量）。

## 里程碑 2：拓展能力

- 小工具合集：管理 GitHub 下载的开源小工具，提供分类与导航。
- 游戏模式：一键切断弹窗通知。
- 反游戏模式：有作业未完成时随机提高通知频率并抢夺焦点，开启后在有作业期间无法关闭。
- 日志系统：清晰美观的文件分类变更记录（v0.8.3；v0.8.2 可先做最小实现）。
- 成绩计算：根据作业提交情况与自定义成绩，提醒时自动计算"若本次作业不交，期末至少需要考多少分才能不挂科"。
- 桌面宠物：支持拖拽文件/文件夹直接纳入自动归档流程，带小动画与互动。
- 成就系统：提供与软件高级功能/学习功能相关的可解锁成就。
- 下载自动化：接入课程平台并解析页面，自动化完成作业下载、归档与排期。
- 特化模型：本地可运行、低空间占用、高效率的分类小模型。

## 已知技术挑战

- 避免直接归档正在下载的文件：计划通过检测文件读写占用判断下载是否完成。
- 应对"浏览器边下边写"的下载方式：计划设置缓冲文件夹，对特殊情况隔离等待。
