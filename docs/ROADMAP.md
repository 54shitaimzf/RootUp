# 开发路线图（ROADMAP）

> 本路线图由立项阶段的功能规划整理而来，按里程碑组织，后续可拆解为 GitHub Issues 跟踪。

## 当前状态

- v0.1.0（已完成）：Tauri v2 + React 框架与 UI 基础——系统托盘、关闭即销毁/托盘重建、单实例、主题三态（浅色/深色/跟随系统）、中英双语切换、设置持久化、左导航五页面骨架。

## 当前迭代（规划中）：文件监听与索引
> 迭代 A（监听 + 索引 + 文件页 + 日志）与迭代 A.5（全量扫描、分类标签、搜索语法、文件门户、防重叠与误删防护）均已完成。迭代 B 的「智能分类 / 自动归档」须先满足安全前置（事务性移动 + 撤销 + 目标存在性检查）；AI / 课程匹配分类 = 新增 `Classifier` 实现并追加进分类链。

范围与详细设计见 [docs/FILE_MONITORING.md](docs/FILE_MONITORING.md)：

- 监控目录设置：`Settings` 增加 `watched_dirs`，可增删、重启保留。
- 文件监听管道：notify + 事件归一 + 去抖 + 忽略清单 + 稳定确认 + 状态机。
- 文件索引库与文件页浏览（列表/搜索）。
- 独立日志系统模块（文件滚动日志，供所有子系统写入）。
- 验收：往监控目录丢文件，几秒内出现在文件页；下载中文件不误报；目录与配置重启保留。

里程碑 1 中的"文件夹监听"由本迭代覆盖；"快捷路径/智能分类/自动归档"在后续迭代实现。

## UI 与扩展基线

- 品牌基调：薄荷绿主色 + 中性灰，浅色/深色双主题（跟随系统），圆角 8–12px，柔和层级阴影。
- 设计令牌：`src/theme/tokens.css` 统一定义颜色、圆角、阴影与字体；皮肤 = 一套令牌覆盖，后续新增皮肤不改组件。
- 国际化：i18next + `zh-CN` / `en` 字典；新增语言只需添加字典并在后端校验常量登记。
- 后台策略：关闭即销毁窗口，后台零浏览器内存；托盘一键重建。

## 里程碑 1：MVP 核心能力

- 后台常驻：系统托盘显示图标，持续在后台运行。
- 文件夹监听：支持指定目录的实时变更监听（当前迭代）。
- 课程表记录：允许用户简单快速地创建课程表，供后续智能分类使用。
- 自动解压缩：智能解压下载的压缩包，确保内容被解压到一个独立文件夹。
- 智能分类：下载完成后自动弹窗，根据文件名、类型与下载时间猜测分类标签，支持一键分类归档。
- 项目生命周期管理：清除/归档过期作业项目，一键规范命名并打包压缩。
- 快捷路径：创建自定义图标的打开脚本，可放置于桌面等醒目位置，一键打开未完成作业（后续迭代）。
- 临期提醒：作业到期前进行克制有度的弹窗提醒。

## 里程碑 2：拓展能力

- 小工具合集：管理 GitHub 下载的开源小工具，提供分类与导航。
- 游戏模式：一键切断弹窗通知。
- 反游戏模式：有作业未完成时随机提高通知频率并抢夺焦点，开启后在有作业期间无法关闭。
- 日志系统：清晰美观的文件分类变更记录。
- 成绩计算：根据作业提交情况与自定义成绩，提醒时自动计算"若本次作业不交，期末至少需要考多少分才能不挂科"。
- 桌面宠物：支持拖拽文件/文件夹直接纳入自动归档流程，带小动画与互动。
- 成就系统：提供与软件高级功能/学习功能相关的可解锁成就。
- 下载自动化：接入课程平台并解析页面，自动化完成作业下载、归档与排期。
- 特化模型：本地可运行、低空间占用、高效率的分类小模型。

## 已知技术挑战

- 避免直接归档正在下载的文件：计划通过检测文件读写占用判断下载是否完成。
- 应对"浏览器边下边写"的下载方式：计划设置缓冲文件夹，对特殊情况隔离等待。
