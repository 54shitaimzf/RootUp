# 开发路线图（ROADMAP）

> 版本 = 一个可发布闭环。0.8.3 为存量补丁；0.8.x 为迭代线（Radix · 扎根，架构小步 + 功能，允许 schema 小步迁移）；0.9.x 为平台线（Hedera · 展藤，AI + 生态）；v1.0 为稳定发布里程碑（Mentha · 常青薄荷）。每个版本均带验收，可独立发布。

- v0.1.0（已完成）：Tauri v2 + React 框架与 UI 基础——系统托盘、关闭即销毁/托盘重建、单实例、主题三态、中英双语切换、设置持久化、左导航五页面骨架。
- v0.2.0（已完成）：文件监听与索引（迭代 A / A.5）——全量扫描与防误删、分类标签与搜索语法、可配置规则与方案、文件页门户、搜索自动补全与频率筛选、习惯数据收归应用管理、浮窗与皮肤基础、设置弹窗体验统一。
- v0.3.0（已完成，本迭代）：全面审查加固——修复实时合并截断与目录规范化同步；组件测试设施覆盖 UI 边界；`ui:` 行为日志与日志驱动冒烟；CI 完整构建、失败日志 artifact、冒烟与架构校验；架构依赖校验脚本。

## 版本规划（已固定）

> 顺序即依赖链：补丁 → 架构地基 → 性能 → 单元同构 → 功能 → 观测 → 发布 → 平台线 → 稳定发布。每个版本 3~4 项同类工作，规模适合单次迭代闭环。
> 代号：0.8.x = Radix（扎根），0.9.x = Hedera（展藤），v1.0 = Mentha（常青薄荷）。

### v0.8.3「存量体验补课」（补丁）

- 自绘下拉与输入过滤：共享 `Select` 重写为自定义下拉（portal 弹层、键盘导航、搜索过滤、视口钳制、图标/色点/选中勾），替换全部原生下拉。
- 项目页体验：原生“浏览…”、文件夹拖拽、常用目录一键添加、来源标记（手动 / 自动发现）、粘贴清洗与实时校验（复用 0.8.2 监控目录体验组件）。
- 项目识别修复：向上查找跳过噪声目录（node_modules / target / dist / .git / __pycache__ 等）；特征矩阵扩充（CMake / PHP / Ruby / Dart / Flutter / Kotlin / Swift / Android 等）；项目卡片显示识别依据（命中的特征文件）。
- 托盘图标：多尺寸 ICO（16/20/24/32/48/64）替换单张 PNG；待办角标随 `refresh_tray` 切换。
- 验收：项目页与监控目录体验一致；识别修复全矩阵测试；托盘深浅主题清晰；无 schema 变更；版本提交前强制运行 `pre-release-check.ps1`（含 AI 真实全链路深链验收）；性能基准体系建立（自研 harness，0.8.3 初始基线入库）。

### v0.8.4「存储与扫描地基」（架构）

- 扫描器重构：抽取 `FileEnumerator`（path / size / modified / is_dir / is_symlink）与 `DeltaSource`（事件流 → upsert / delete）接口，walkdir 为默认实现；差集从内存快照改为 SQLite 临时表 / keyset（内存 O(批次)）；评估 jwalk（仅目录多 / 深生效）；快速路径与 walkdir 等价测试。
- SQLite 调优与存储治理一阶段：`journal_size_limit` / `wal_autocheckpoint` / 空闲与关闭 checkpoint / `synchronous=NORMAL` / `mmap_size` / `cache_size` / `busy_timeout` / `PRAGMA optimize`；墓碑保留期（30 天）与启动清理；损坏备份保留最近 3 份；快捷图标对账；设置保存合并写 / 去抖。
- 启动与后台优化一阶段：setup 各阶段埋点；非关键服务延迟到窗口显示后；scanner / 自动归档空闲轮询事件化；日志批量缓冲 flush；空闲 RSS / CPU 入冒烟基线。
- 文件列表排序与翻页交互：手动排序方式（名称 / 类型 / 大小 / 修改时间 / 标签，升序降序，中文 locale 稳定排序规则）、加载更多与滚动位置保持、翻页状态可感知；索引级 keyset 分页 / COUNT 治理仍归 v0.8.5 落地。
- 统一输入边界与合法性检查：监控/项目目录（清洗、长度、非法字符、保留名、UNC、环境变量展开后校验、越权路径）、设置枚举与范围（close_action、reminder_lead_days、语言白名单）、命令与深链参数白名单、课程/作业/标签/规则/方案/习惯字段（必填、长度、日期、周次、同周冲突、label_key 合法性）、本地 JSON 未知字段容错、搜索语法边界、拖拽/浏览/粘贴结果校验；Rust 强校验 + 前端即时校验双保险，边界矩阵测试集中维护。
- 验收：等价测试全绿；启动 / 扫描 / 内存基线建立。

### v0.8.5「快速扫描与查询」（性能，已发布）

- NTFS 快速基线扫描（MFT/USN）+ 增量对账（USN 变更日志）+ 枚举兜底（`FindFirstFileEx` + `FIND_FIRST_EX_LARGE_FETCH` 或 `NtQueryDirectoryFile`）；拒权 / 非 NTFS / 网络盘自动降级 walkdir；硬链接去重、不跟随重解析点；依赖评估后引入 `ntfs-core` / `usn-journal-rs`。
- 索引与查询优化：keyset 分页替代 OFFSET、组合索引、COUNT 治理或延迟总数、标签过滤实测（逗号串 + LIKE vs 拆表 / 生成列）、FTS5 trigram 评估（CJK 单 / 双字保留 LIKE 回退）。
- 搜索语法增强：标签多值默认 OR 保持不变；新增显式 AND 语法（如 `label:a +label:b` 或 `label:a AND label:b`），后端解析、前端补全与帮助文案同步，边界矩阵补用例。
- 分类 / 规则匹配加速：Aho-Corasick 多模式匹配（课程名、忽略规则、文件名模式一次同时匹配）。
- 验收：5–10 万文件量级查询 / 扫描 / 滚动流畅；MFT 与 walkdir 结果一致；现有功能零回归；性能基准对比报告（自研 harness，15% 警示）。

### v0.8.6「规模与体积」（性能，两阶段执行）

> 0.8.6 合并 0.8.5 对接项，拆为两个阶段独立验收：阶段一「监控与查询性能」（风险最高放最前），阶段二「规模与体积」；全部完成后统一发布。
> 状态：阶段一已实施（2026-08-09，代码与单测就绪；真实卷 MFT 提权验收与差分样本夹具待管理员环境补充）。

**阶段一「监控与查询性能」**

- MFT 快速基线 + USN 增量对账：首次以 MFT（提权验收后转默认）或 walkdir 建基线，日常读 USN 变更日志增量对账（upsert/delete 喂入现有差集链路）；权限 / 非 NTFS / 网络盘 / USN 日志裁剪自动回退并记录降级原因。
- FTS5 trigram 文本索引：附属表与 files 的同步 / 重建 / 一致性设计，评估后采纳；CJK 单字保留 LIKE 回退。
- 索引维护复核：安静环境复核 0.8.5 三个索引对 100k 扫描 / 重分类的写入代价，验证 `idx_files_type` 去留，必要时再收窄。
- 监控目录缺失对账：目录被删 / 盘符卸载 → 相关索引记录标记 deleted 或挂起并提示（修复幽灵文件与“目录不可访问后残留”），与 0.8.8 统一错误码体系预留对接。
- 验收：MFT/USN 与 walkdir 等价；降级矩阵全绿；写入代价回落或有明确去向；对账用例全绿。

**阶段二「规模与体积」**

- 前端渲染：文件列表虚拟滚动（只渲染可视行，布局不变；滚动位置 / 键盘导航 / 选中态 / 加载更多回归测试）。
- 应用体积压缩（Rust）：`[profile.release]` 启用 `lto` / `codegen-units=1` / `strip` / `panic=abort` / `opt-level=s|z`；cargo-bloat 审计并精简 feature；UPX 仅对照实验不作为默认。
- 前端体积（路线 A 落地）：React.lazy 页面级分割（首包仅文件页，加载占位高度不跳动）、语言包按需加载、Vite manualChunks 与构建产物压缩（gzip / brotli 评估）、首屏 JS ≤200KB。
- 性能基线与测量：0.8.6 全量重测并以 0.8.6 vs 0.8.5 为最新对比；帮助中心 0.8.6 更新亮点入库。
- 验收：体积 / 内存 / 启动指标达到基线；虚拟滚动与分包零布局回归；性能基准对比报告（自研 harness，15% 警示）。

### v0.8.7「单元同构」（架构，允许 schema v3 迁移）

- 索引升级为 `units` 表（v3）：`kind: file | project | software` + 通用字段（path / name / labels / state / first_seen / modified）+ 各类扩展字段（文件大小 / 类型、项目类型、软件信息）。
- 统一查询与筛选：`kind:` 语法、搜索覆盖全部单元、文件页“全部 / 文件 / 项目 / 软件”视图；统一详情、标签、打开、定位、归档、快捷方式操作。
- 软件单元识别：权威标记（PAF / Scoop / 便携启动器）+ 结构启发式 + 置信度 + 用户裁决；PE 版本资源校验评估。
- 项目 / 课程挂钩完整版：项目名 / 路径按课程名与别名匹配，课程详情同时展示相关文件与项目。
- 图标消费模型统一（皮肤接入点前置）：硬编码 UI 图标统一经 `theme/icons.ts` 专用路径导入（新增架构断言禁止组件直连 `lucide-react`），为 v1.3 皮肤图标集替换预留单点；数据图标（标签 / 方案 / 软件单元）建立 `lib` key 注册表（`resolveIcon` 统一未知 key 回退 + fixtures 图标 key 校验门禁），file / project / software 共用同一 key 空间。
- 验收：既有 files 查询迁移零回归；课程详情同时展示文件与项目；软件识别裁决可持久化；图标 key 注册表校验与直连门禁全绿。

### v0.8.8「整理与回收」（功能）

- 智能解压：压缩包自动解压到独立文件夹，纳入索引 / 分类 / 归档链路；评估 zip 依赖与安全边界（路径穿越、解压炸弹、超大文件）。
- 应用内删除走回收站：统一删除操作移入系统回收站（可恢复），并记入 action_log。
- 文件分类变更日志 v1：记录分类 / 归档 / 撤销历史，可查看、可追溯、可一键撤销（复用 archive_ops / journal 模式）。
- 可靠性加固：启动归档对账（按 source/dest 存在性修复索引或标记异常）、启动清理 `*.json.tmp`、子进程强杀中断集成测试。
- 错误响应与对账机制（覆盖用户 / 边界 / 环境 / 文件夹四类变动）：
  - 统一错误码注册表：稳定 `error_code` + 用户可读文案 + 日志上下文，前端统一展示并给出可重试 / 可忽略 / 需用户介入的分级；
- 文件夹与环境变动对账（监控目录缺失对账已提前至 0.8.6 阶段一）：权限变化、盘符卸载 / 重挂载、网络盘断开 → 索引挂起 / 清理与提示；归档目标不可写、跨盘、文件被占用 → 明确错误与重试；
  - 用户与边界行为：重复提交 / 快速连续点击幂等与节流、批量上限、非法输入统一拒绝（沿用 0.8.4 输入边界矩阵）、损坏数据文件（settings / study / labels / db）备份回退 + 提示；
  - 验收：错误码注册表、文件夹缺失对账、占用 / 跨盘 / 上限 / 幂等用例全绿；对账挂载点与事件源约定见 ARCHITECTURE。

### v0.8.9「项目治理」（功能）

- 验收：三层出口一致；导出诊断包可用；冒烟事件全绿。

## UI 与扩展基线

- 品牌基调：薄荷绿主色 + 中性灰，浅色/深色双主题（跟随系统），圆角 8–12px，柔和层级阴影。
- 设计令牌：`src/theme/tokens.css` 统一定义颜色、圆角、阴影与字体；皮肤 = 一套令牌覆盖，后续新增皮肤不改组件。
- 国际化：i18next + `zh-CN` / `en` 字典；新增语言只需添加字典并在后端校验常量登记。
- 后台策略：关闭即销毁窗口，后台零浏览器内存；托盘一键重建。
- 交互规范：Windows“是左否右”按钮顺序；IconButton 必有可读 label 与 tooltip；动效遵循令牌并尊重 `prefers-reduced-motion`。

## 已知技术挑战

- 避免直接归档正在下载的文件：计划通过检测文件读写占用判断下载是否完成。
- 应对“浏览器边下边写”的下载方式：计划设置缓冲文件夹，对特殊情况隔离等待。
- NTFS MFT/USN 快速扫描边界：仅本地 NTFS 卷可用，原始卷读取需管理员权限；USN 日志可能被裁剪或未启用，不能作为唯一数据源；MFT 硬链接与重解析点需去重 / 跳过；失败或拒绝提权时一律回退 walkdir，保证行为等价。
- 智能解压安全边界：路径穿越、解压炸弹、超大文件、符号链接逃逸；先评估 zip 依赖再实现（v0.8.8）。
