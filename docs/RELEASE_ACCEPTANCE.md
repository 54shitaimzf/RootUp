# 发布验收清单（Release Acceptance）

> 自动化测试覆盖引擎/存储/UI 单点与关键链路；以下项目需在真实 Windows 环境手动验收一次，
> 作为 0.7.0 及后续版本的发布门槛。每项通过后勾选并注明版本号。

## 归档与撤销

- [ ] 设置“归档设置”：填写归档根（与文件同盘）、开启自动归档后保存，重启后设置保留
- [ ] 归档根与监控目录相同时被拒绝并提示
- [ ] 单文件归档：文件移到 `归档根/<大类>/`，文件页出现“已归档”徽标，搜索仍可命中
- [ ] 批量模式：勾选多个文件 → 严格确认 → 归档；部分失败时成功项保留并提示失败原因
- [ ] 筛选/搜索生效时“归档当前筛选结果”出现；超过 200 个时提示收窄
- [ ] 撤销：归档后立即撤销、重启后从“最近归档”撤销，文件回到原位且状态恢复“已索引”
- [ ] 原位置被新文件占用时撤销被拒绝且不破坏任何文件
- [ ] 同名冲突：目标已有同名文件时生成 `名称 (2).ext`，原文件不被覆盖
- [ ] 跨磁盘归档被拒绝并给出“同盘”提示
- [ ] 文件被占用（Word/编辑器打开）时归档失败并给出可理解提示
- [ ] 归档根位于监控目录内部：移动进去的文件不会被重复索引
- [ ] 自动归档：开启后向监控目录丢一个分类明确的新文件，数秒内自动归档；other/未知类型留在原地
- [ ] 项目归档：项目卡片归档 → 整目录移动 → 桌面快捷方式双击仍能唤起；撤销后快捷方式恢复
