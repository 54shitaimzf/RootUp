# 项目愿景（VISION）

## 一句话定位

RootUp 是一款面向学生场景的智能自动化文件整理与分类桌面工具：帮助用户在下载目录、桌面和课程资料之间建立秩序，让文件"随下随理、随找随到"。

## 背景与机会

随着课程资料、项目代码、实习文档和个人文件持续增长，桌面环境里普遍存在"文件散乱、命名不规范、查找效率低、重复整理耗时"的问题。现有方案要么依赖手工拖拽分类，要么偏向企业场景，缺少针对学生学习节奏与作业场景的轻量化自动整理产品。

RootUp 的机会点在于：以"低学习成本 + 自动化执行 + 可解释、可自定义规则"帮助学生完成日常文件治理，把碎片化的整理行为沉淀为可复用的整理习惯与规则资产。

## 目标用户

- 主要用户：在校大学生（本科/研究生），课程项目与资料密集。
- 次要用户：初入职场的实习生与技术新人，文件管理需求类似。
- 目标平台：Windows 桌面端，强调本地文件管理与系统托盘常驻。

## 核心痛点

- 桌面与下载目录文件堆积，检索成本高。
- 作业/实验报告版本混乱，容易误提交旧文件。
- 项目资料跨课程、跨学期分散，复用困难。
- 手工分类流程重复，时间投入高但收益不稳定。
- 现有工具学习使用成本高，缺乏针对学生场景的优化。

## 价值主张

- 让用户以最少操作完成"发现混乱 → 自动整理 → 持续维护"。
- 将文件整理从一次性动作升级为持续、可配置、可追溯的系统能力。
- Download free, Download Freedom：下载自由。

## 差异化

- 聚焦学生高频目录（桌面、下载、课程资料）与工具管理场景，同时保留通用文件管理能力。
- 自带通用清晰的初始分类与规则，上手即可用，基本无需学习。
- 人工可控：默认只读取文件标题完成分类，尽可能本地化或由用户提供 API Key，限制 AI 操作权限，提升信任。
- 开源免费，预留扩展空间，可根据文件类型扩展更多功能。

## 产品原则

- 简单优先：关键路径不超过 3 步完成配置。
- 隐私可控：只使用文件名完成分类归档，主要依赖历史记忆、手动配置与本地模型。
- 特色功能：提供面向学生与小工具处理的特色功能。

## 核心产品方案

### 关键流程

1. 首次安装后设置核心下载目录（建议避开系统盘）。
2. 文件变更触发监听，弹出分类弹窗；默认提供标签，也可手动配置类别。
3. 自动归档文件，并记录到检索用数据库中。

### 单元机制

针对可能存在的应用、电视剧等文件夹，将其视为一个"单元"处理，单个文件同样视为一个单元；每个单元内可以设置新的文件分类树。软件维护一张文件表，用于快速查找分类与导航。

### 偏好标签

对每个下载文件，根据文件类型与最近下载习惯维护偏好标签列表，提供初始标签；同时智能识别文件名，调整默认标签或增加新分类标签，减少用户操作步骤。选择标签时支持父标签/子标签逻辑（例如"学习资料 → 数学"）以生成文件树；若文件属于两个平行分类，优先保存在文件数量少的文件夹下，并在数据库中维护两个标签。

### 快捷打开

生成使用指定软件打开某文件/文件夹的脚本，或直接生成可执行文件的快捷方式，供用户一键跳转，也可在软件内打开项目/工具时调用。

### 整理方式演进

以"索引先行、物理归档渐进"实现自动化：文件落地立即建索引（零风险），
再逐步升级为分类建议、受控归档与全自动归档。信任顺序是"先证明看得懂，再获得移动权"；
物理组织结构是终局，让用户在资源管理器等任何入口都能享受秩序。

### 打开方式与分类闭环

分类管理"文件在哪"，打开方式管理"怎么用"：软件内一键打开项目/文件，
并可将打开方式封装为桌面快捷方式；归档移动与快捷方式路径联动，保证始终可用。

### 作业周期设置

识别到作业类型时，根据最近上过的课/临近的课（根据用户习惯打标签：习惯提前完成者倾向于最近课程，拖延者倾向于临近课程，可设置成就或由小模型预测），或根据文件名猜测所属课程；猜中课程后再猜测截止日期（按一般课程以周为单位的习惯），用户可自行加减微调。

## 技术路线

- 客户端形态：Tauri v2 桌面应用（Rust 桌面壳 + React/TypeScript 前端）。
- 核心模块：文件监听、UI 与后台、分类、数据库、作业管理。
- 扩展模块：桌面宠物、成就系统等。
- 资源管理：本地配置文件持久化，保障离线可用。
- UI 基调：绿色系品牌色、深浅双主题（跟随系统）、设计令牌驱动的皮肤扩展、中英双语界面。
